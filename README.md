# NewsGist — Get the gist, skip the noise.

> Too many tabs. Too many words. Not enough time. NewsGist fixes that.

NewsGist fetches real-time headlines and transforms them into crisp summaries with sentiment analysis — so you know not just *what* happened, but *how it feels*.

---

## What It Does

- **Real-time headlines** — fetches the latest news as it breaks
- **One-liner summaries** — quick scan when you're short on time
- **Detailed summaries** — depth when you want it
- **Sentiment analysis** — instantly see if a story is positive, negative, or neutral
- **Clean interface** — no clutter, just the essentials

---

## Tech Stack

Python · Flask · REST APIs · NLP · JavaScript · HTML · CSS

---

## Getting Started

```bash
git clone https://github.com/vedantkolhapure/newsgist.git
cd newsgist
pip install -r requirements.txt
python app.py
```

Open `http://localhost:5000` — search or browse headlines, get summaries and sentiment on demand.
